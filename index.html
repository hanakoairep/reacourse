What it can do, and what it can't

The course is specific about the edges, because the edges are where people waste a weekend or ship something that is not theirs.

it_can.txt
  • Open Electron, .NET, native, APK, WASM, Go and firmware targets
  • Turn one function into pseudocode and then into named, typed code
  • Show the exact address, bytes and call site behind every claim
  • Trace a single feature from a click down through the layers
  • Diff two releases and tell you what actually changed
  • Audit an APK for permissions, trackers and the domains it talks to
  • Recover the interface of an unverified contract from raw bytecode
it_cannot.txt
  • Touch code that runs on someone's server and was never shipped to you
  • Hand you the original source, because a decompile is a reconstruction
  • Beat stage-three obfuscation, which benchmarks at zero
  • Make a stripped C++ binary as easy as a Unity game
  • Give you an IDA, Hopper or JEB license
  • Make copied code legal because an agent pasted it

Reading an app on your own machine is learning. Rebuilding a feature from its behavior is how the industry has worked since the eighties. Copying the code, cracking paid features or publishing someone else's decompile is the part that gets you sued. Part five is about staying on the right side of that line on purpose, not by luck.

Before you buy

requirements.md

What do I need?

Node 22 or newer, an agent such as Claude Code, and a machine you own. Two of the six target types need no engine at all, so you can finish the first two parts before installing Ghidra.

skill_level.md

Do I need to know assembly?

No. The whole point is that you read findings, not instructions. You do need to be comfortable in a terminal and able to read code in one language.

legal.md

Is this piracy?

No, and part five explains exactly why, with the cases that settled it. The course teaches clean-room rebuilds from behavior, and it is explicit about what crosses the line.

access.md
